المشاريع التالية تُطبِّق ACP مباشرةً، أو تربط وكلاء ACP ببيئات أخرى، أو تدعم سير عمل وكلاء البرمجة المجاورة.

- [JetBrains](https://www.jetbrains.com/help/ai-assistant/acp.html)
- [neovim](https://neovim.io)
  - عبر إضافة [CodeCompanion](https://github.com/olimorris/codecompanion.nvim)
  - عبر إضافة [carlos-algms/agentic.nvim](https://github.com/carlos-algms/agentic.nvim)
  - عبر إضافة [yetone/avante.nvim](https://github.com/yetone/avante.nvim)
  - عبر إضافة [hermes.nvim](https://github.com/Ruddickmg/hermes.nvim)
- [Obsidian](https://obsidian.md) — عبر إضافة [Agent Client](https://github.com/RAIT-09/obsidian-agent-client)

## الموصلات (Connectors)

هذه الموصلات تجسر ACP ببيئات وطبقات نقل أخرى:

- [ACP to AG-UI](https://github.com/namanrajpal/acp-to-agui) — يجسر أي وكيل ACP لواجهات الويب عبر أحداث [AG-UI](https://docs.ag-ui.com)
- [stdio Bus](https://stdiobus.com) — نواة stdio حتمية توفر توجيه مستوى النقل لبروتوكولات وكلاء ACP/MCP.
